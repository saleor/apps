The "Show AvaTax tax code" command palette action now lets you fix the mapping without leaving the modal. Before, it was a read-only summary that told you to go to the app configuration; now the AvaTax tax code is a searchable select you can change on the spot, and an "Open app" button takes you to the app when you need to do more. The modal content also sits in a padded card instead of being flush against the top edge. The product details sidebar widget is unchanged.
